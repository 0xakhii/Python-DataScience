# Python-DataScience

A structured 5-module **Python for Data Science** curriculum covering Python fundamentals, array and image manipulation with NumPy/OpenCV, tabular data analysis and visualization with Pandas/Matplotlib, object-oriented programming, and data-oriented design patterns.

## Modules Overview

Each module has its own complete guide explaining concepts, formulas, execution traces, function/class breakdowns, and standard-library/third-party references:

| Module | Directory | Exercises | Core Topics | Guide |
|:---|:---|:---|:---|:---|
| **Module 0 — Starting** | [`Starting/`](Starting/) | `ex00` – `ex09` | Built-in collections, `datetime`, type/null checks, CLI args, regex, `lambda`, dictionaries, `yield` generators, `pyproject.toml` packaging | [Starting/README.md](Starting/README.md) |
| **Module 1 — Array** | [`Array/`](Array/) | `ex00` – `ex05` | BMI & thresholding, 2D array slicing, OpenCV image loading (BGR → RGB), cropping/zooming, manual matrix transpose, RGB color filters | [Array/README.md](Array/README.md) |
| **Module 2 — DataTable** | [`DataTable/`](DataTable/) | `ex00` – `ex03` | Pandas CSV loading & validation, time-series plotting, Gapminder `K`/`M`/`B` parsing, inner joins, log-scale scatter plots | [DataTable/README.md](DataTable/README.md) |
| **Module 3 — OOP** | [`OOP/`](OOP/) | `ex00` – `ex04` | Abstract base classes (`ABC`), `__str__`/`__repr__`, `@classmethod`, diamond inheritance & C3 MRO, `property()`, operator overloading, `@staticmethod` | [OOP/README.md](OOP/README.md) |
| **Module 4 — DOD** | [`DOD/`](DOD/) | `ex00` – `ex03` | `*args`/`**kwargs` & descriptive statistics, closures & `nonlocal`, decorator factories, `@dataclass`, `field()`, `__post_init__` | [DOD/README.md](DOD/README.md) |
